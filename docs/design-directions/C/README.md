# NexuAlpha - Direction C: Bold Swiss poster

Files: home.html, compare.html, binance.html (single-file, hand-written CSS; generated from build.py only to share tokens). Shots in shots/ (1440 + 390 full page).

## Concept
Editorial poster logic: one heavy rule, one giant number, one flat colour field per section. Exchanges are typographic rows (index, huge name, huge tomato fee figure, one-line verdict, code + CTA), never cards. Numerals are the graphic language: "08" hero field, 01-04 method, giant fee figures, BINANCE as a full-width wordmark.

## Tokens
- Colour: paper #F1ECE2, ink #161412, tomato #E5381F (paper-2 #E7E0D2 hover only). Two-colour system plus ink; no blue, no gradients.
- Type: Archivo (variable width, 62% condensed, 800-900, uppercase for display) + IBM Plex Mono for labels/codes. Fallback: Inter Display, DejaVu Sans Condensed. 7 steps: 12 / 15 / 20 / 32 / 64 / 120 / 240 (mobile 12/15/20/24/44/60/136).
- Grid: 12 col, 24px gutter (16 mobile), 48px margin (16 mobile), 4px-multiple spacing. Rules: 8px structural, 2px row dividers. Labels max 2 words.

## Distinctiveness
Poster scale contrast (240px numerals vs 12px mono), flat colour bands instead of surfaces, rows with a verdict tucked under the name, referral code printed as a ruled data line rather than a badge. Fee data are published base-tier rates, flagged "checked Oct 2026" - verify before launch.
