# OG cards v2 review samples

Generated by `node scripts/render-og-cards-v2-samples.mjs`.

Article source: local published feed, slug `okx-vs-kraken-proof-of-reserves-disclosure-scope-checklist`. Exchange fees, rebates and invite codes use the current checked-in facts and public CTA projection.

The liquidation/funding samples use the recorded real collector snapshot `tests/fixtures/market-data/market-events.live-v2-2026-10-13.json` (2026-10-13). These are historical review images, not a live-market claim. The production route reads its mounted current snapshot and prints the full UTC timestamp.

All cards: 1200×630, #08090C, existing brand mark, dot grid and teal/blue accents. Article titles have at most two lines; missing logos and unverified numbers are omitted. PNG logo tiles are lossless exports of the existing 128px WebP tiles because resvg 2.6.2 cannot decode WebP. No new browser dependency.

See final-tests.log for separate warm cached-request and native render + PNG-encode measurements. Native rendering is measured with explicit local fonts, matching the OG_FONT_DIR mode. Full system-font scanning and the production Linux font mount are not covered by that latency claim. Set OG_FONT_DIR to the production DejaVu/WenQuanYi font mount for deployment rendering.

Round 2: symmetric comparison columns, centred gradient-ring VS badge, complete LTR fee pairs within RTL layouts, plain localized fee insights, and clipped 24px logo tiles with accent halos.
