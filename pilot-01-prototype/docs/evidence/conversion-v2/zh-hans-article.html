    1. OKX says its Third Party App IP Whitelist limits API key usage to whitelisted broker servers when the broker supports the feature.
    2. OKX tells brokers to provide public server IP addresses in IPv4, IPv6 or CIDR format for whitelisting.
    3. OKX's user flow says users create an API key for the purpose of binding third-party apps and select a whitelisted third-party app from the dropdown.
    4. OKX's API Guide says API keys can be bound to IP addresses and trade or withdraw keys not linked to IP addresses may expire after 14 days of inactivity.
    5. OKX's API Agreement requires commercially reasonable security measures, including minimum permissions, MFA, encrypted storage, IP allowlisting where available and rotation after suspected compromise.
