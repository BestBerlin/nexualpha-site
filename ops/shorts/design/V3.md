# v3 design and verification contract

Retain the existing NexuAlpha ink/blue tokens, logo SVG, Inter font and Nexubo point rig. Reuse one validated daily source for all formats, translations and platform metadata. The number is the hook; Nexubo supplies a recognizable guide without obscuring it. The final frame directs viewers to the full liquidation board.

The v2 caption length assertions are replaced intentionally: complete sentences are timed as captions, and visual line wrapping is separate from copy segmentation. The v2 fixed hero-height and horizontal-condensation assertions are replaced by measured font fitting and safe-bound checks. Portrait and square use separate geometry, without cropping. Financial validation tests remain intact.

Acceptance checks:
- Nine strings tables with Arabic direction metadata; default daily run produces the eight requested initial locales.
- Five six-second scenes (30s caption-only); voiced output fails unless measured total fits 25–35s.
- Portrait and square H.264/AAC streams, 30 fps, poster PNG and SRT per format.
- Complete-sentence captions, signed funding decimals intact, no horizontal text scale.
- Covered-venue and interval caveats stay visible and localized.
- Actual glyph bounds across every locale, format and count-up state, including Arabic RTL and LTR numeric values.
- CTA metadata for YouTube/TikTok/X/Telegram goes to the correct localized page with platform attribution, no partner codes.
- Live EN/VI samples checked from one saved source snapshot; generated samples stay outside the commit.
- Clone narration uses only the installed owner reference/model with network downloads disabled. Voice playback remains a separate optional validation when the runtime is provisioned.

GSAP uses the existing vendored library in offline HTML review surfaces; a paused timeline supplies deterministic scene seeking. Hyperframes scene comments/metadata expose frame duration and concept. MP4 encoding uses the existing Resvg/ffmpeg pipeline rather than adding another renderer dependency. Chart geometry stays proportional to the raw snapshot. The end card retains a single domain text element and persistent brand mark/wordmark.
